# Пилот: оптимизация устойчивости сетей

Основная GNN-регрессия выбрана по валидации: **mse**. Чем выше R, тем лучше.

RankNet относительно неё: **+3.10%**; исследовательский интервал по исходным сетям [+1.70%, +4.64%].
Повторная оценка тех же найденных решений на независимых сценариях: **+3.22%**.

Тестовых исходных сетей: 8. Бюджет каждого поиска: 96 оценок по 4 сценариям. Это пилот на одной обучающей выборке; seed не считаются независимыми сетями. Глобальный оптимум неизвестен.

При равных степенях порядок удаления определяется фиксированными случайными приоритетами. Независимые сценарии не выбирают модели или решения. Бюджеты истинных оценок включают начальную популяцию; обучающие, валидационные и проверочные траектории учитываются отдельно. Онлайн-время исключает предварительное обучение.

Сохраняются степени вершин, связность и число рёбер; число новых рёбер ограничено 20% исходного числа (с округлением вверх). Оптимизируется устойчивость к адаптивному удалению узлов по степени. Другие виды отказов и реальные инфраструктурные ограничения не тестируются.

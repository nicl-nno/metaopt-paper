# MetaOpt: код и результаты экспериментов

Здесь собраны актуальный код и сохранённые результаты проверки **ранжирования против GNN-регрессии в оптимизации с фиксированным бюджетом реальных оценок**: генеративный дизайн ферм, устойчивость сетей и статистический анализ.

**Актуальный текст статьи ведётся отдельно в [ICCC26_MetaOpt_text](https://github.com/nicl-nno/ICCC26_MetaOpt_text), связанном с Overleaf.** Файлы `main.tex`, `main.pdf`, `evidence/` и старый ZIP в этом репозитории сохранены как исторический снимок черновика; его описание — [MANUSCRIPT_SNAPSHOT.md](MANUSCRIPT_SNAPSHOT.md).

## Состояние опубликованного снимка

Снимок `snapshot_20260908_final` содержит **10 568 файлов результатов**: около **1 174 МиБ исходных данных**, сжатых без потерь до **163 МиБ** в 77 ZIP-архивах. Все архивы находятся непосредственно в GitHub-репозитории; Git LFS и внешнее хранилище для их получения не нужны. Сохранены offline-данные, веса моделей, история обучения, исходные результаты отдельных поисков, траектории, конечные конструкции/графы, аудиты, конфигурации, frozen snapshots и журналы. Предыдущий частичный снимок сохранён как исторический.

- **Фермы:** завершённая основная серия `overnight_20260906_v2`, пять основных и пять диагностических блоков; пилоты и smoke-прогоны сохранены отдельно.
- **Устойчивость сетей:** `replication_20260907_v1` завершена и проверена: 5 блоков, 160 ID-сетей и 40 сетей на 200 вершинах; 8 400 поисков, 1 612 800 онлайн-оценок. При бюджете 96 RankNet даёт +0,956% к выбранной по валидации GNN-регрессии, +4,811% к EA; на 32 новых сценариях +0,902% к регрессии.
- **Статистика:** завершён `final_20260908_v1`: 131 победа из 160 исходных сетей, условный двусторонний тест знаков p=1,10e-16, Holm по 36 сравнениям p=7,70e-16. Все 5 эффектов по обучающим блокам положительны, но точный двусторонний тест по блокам даёт p=0,0625. Тесты исследовательские; условная значимость по сетям не доказывает значимость при повторном обучении. В исходном отчёте две заключительные фразы ошибочно упоминают «два блока»; численные файлы и основной вывод относятся к пяти. Исходные байты сохранены для аудита.

Состояния зафиксированы перед упаковкой и не обновляются от работающих локальных процессов. Манифест содержит временные отметки и исходные состояния. Исторические `LAST_ERROR.json` сохранены: ошибка могла быть восстановлена, поэтому их нужно читать вместе с completion markers и аудитами. Пилоты, технические проверки и независимая основная серия не объединяются в одну статистическую выборку.

## Проверить и распаковать

Из корня этого репозитория, обычным Python без дополнительных библиотек:

```powershell
python tools/research_artifacts.py --verify-members
python tools/research_artifacts.py --extract code/GAMLET
```

Первый вызов проверяет SHA-256 архивов и каждого исходного файла. Второй восстанавливает исходную структуру `experiments/<benchmark>/results/<run>/...`, тоже с проверкой хешей. Файлы с отличающимся содержимым не перезаписываются. Не распаковывайте поверх рабочего каталога активного расчёта.

Новые запуски выполняйте в новых выходных каталогах по [инструкции воспроизведения](code/README.md). Дорогие эксперименты при проверке архивов не запускаются. Статистический анализ остаётся исследовательским; условные тесты по исходным задачам отделены от тестов по обучающим блокам.

## Область переноса

Включены все исходники актуальных новых экспериментов и весь сохранённый вывод этих экспериментов, включая пилоты. Перенесён код исходного GAMLET с сохранением BSD 3-Clause [LICENSE](code/GAMLET/LICENSE). Старые upstream-данные AutoML, его исторические модельные артефакты и журналы, не используемые новыми экспериментами, перечислены как исключённые в `code/SOURCE_MANIFEST.json`; их исходный репозиторий и Git HEAD указаны там же. Виртуальные окружения, Python-кеши, временные файлы и блокировки процессов не включены.

Для создания следующего отдельного снимка из локальной рабочей копии сохранён `tools/export_research.py`. Он не останавливает расчёты и не меняет их код. Публикация снимка не означает завершения активной серии или одобрения научных выводов авторами.

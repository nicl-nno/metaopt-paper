# Ranking versus Regression with Graph Neural Surrogates for Fixed-Budget Design Optimization

Английский рабочий черновик, обновлённый 8 сентября 2026 года. Основной файл — [main.tex](main.tex); собранная версия — [main.pdf](main.pdf). Это черновик для обсуждения с авторами, а не готовая подача.

## Что изменено

- Статья посвящена сравнению **ранжирования и регрессии на одной GNN** в задачах оптимизации с фиксированным бюджетом реальных оценок.
- Добавлены постановки генеративного дизайна ферм и повышения устойчивости сетей перестройкой рёбер с сохранением степеней.
- Внесены завершённые результаты по фермам и диагностика полезности суррогатного отбора. Небольшой эффект относительно регрессии отделён от большого эффекта относительно EA.
- Сетевая статистика приведена только для сохранённого проверенного **промежуточного среза: 2 блока, 64 сети**. Полная серия из 5 блоков, финальная статистика, перенос на 200 вершин и итоговые графики отмечены TODO. Новые файлы работающей серии автоматически не подхватываются.
- Из активного текста убраны старые результаты AutoML, таблицы моделей ранжирования пайплайнов и утверждения об экономии времени. AutoML остался одним предложением как возможное приложение.
- Обзор учитывает близкие работы 2025 года, включая Offline-RaM и ранжирование GNN для выбора молекул. Общая идея ранжирующего суррогата не заявляется новой.

## Сборка

Нужны стандартный LaTeX-дистрибутив и BibTeX. Класс `article` выбран до определения площадки; проприетарный старый шаблон не требуется.

```powershell
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Либо `latexmk -pdf main.tex`. Для сборки не нужны Python, GAMLET, обученные модели или интернет. Красные TODO намеренно видны в PDF.

## Числа и происхождение данных

[evidence/source_manifest.json](evidence/source_manifest.json) связывает локальные источники, снимки и SHA-256. В `evidence/truss/` сохранены завершённая сводка, конфигурации, выбор регрессии и аудиты пяти блоков; в `evidence/network_interim/` — статистика и таблицы фиксированного промежуточного среза; в `evidence/network_protocol/` — протокол полной серии. Это компактный набор подтверждений чисел статьи, а не полный релиз экспериментальных данных и весов.

Для обновления двух численных таблиц из этих снимков и проверки локальной согласованности:

```powershell
python tools/prepare_evidence.py
python tools/check_draft.py
```

`--capture` использовался однократно и отказывается перезаписывать существующий манифест. Он ожидает соседнюю локальную папку `../GAMLET`; для обычной сборки или проверки она не нужна. Проверки не запускают эксперименты и не меняют работающую сетевую серию.

[evidence/claim_map.md](evidence/claim_map.md) описывает источники основных утверждений и ограничения. Машинная проверка чисел и компиляции не равнозначна научному одобрению авторов. Human verification остаётся `pending`.

Код новых экспериментов пока существует как локальное дополнение `experiments/` к GAMLET, поэтому одного старого Git HEAD недостаточно для воспроизведения. Публикация неизменяемого снимка кода и результатов вынесена в TODO R1. Текущая правка не является публикацией или отправкой статьи.

При подготовке использован навык `scientific-writing`; сведения об исследовательском содействии и атрибуция Scientific Agent Skills (Kassis et al., 2026, arXiv:2609.00065) включены в черновик раскрытия использования инструментов. Авторы должны проверить его перед подачей.

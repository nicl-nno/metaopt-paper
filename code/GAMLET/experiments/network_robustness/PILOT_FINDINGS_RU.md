# Пилот: ранжирование при оптимизации устойчивости сетей

Дата: 7 сентября 2026 года. Все 240 поисков завершены. Это исследовательский пилот на одной обучающей выборке, а не окончательная проверка универсального превосходства ранжирования.

## Задача и сравнение

Перестраиваем рёбра связной неориентированной сети, сохраняя степень каждой вершины, число рёбер и связность. Число новых рёбер относительно исходной сети ограничено `ceil(0.2*m)`. Максимизируем R: нормированную сумму размеров крупнейшей компоненты при последовательном удалении вершин максимальной текущей степени. Основная оценка усредняется по четырём фиксированным сценариям разрешения равенств степеней.

Использованы сети Erdős–Rényi и Barabási–Albert по 50 и 100 вершин: 8 обучающих, 4 валидационных и 8 тестовых исходных графов. Разделение выполнено по исходным графам. Обучение использует 1 024 дизайна, валидация — 512. Каждый поиск получает одинаковые 16 начальных решений и бюджет 96 точных оценок. Всего 240 поисков: 3 seed поиска, 2 seed обучения для каждого из трёх суррогатов и четыре контроля без обучения.

RankNet, MSE и log-MSE используют один и тот же GraphSAGE-энкодер из GAMLET и одинаковую архитектуру с 8 417 параметрами. Совпадают начальные веса, обучающие примеры и число шагов оптимизатора. Регрессионный вариант выбран по валидации до оценки тестовых результатов: MSE; log-MSE имеет тот же агрегированный валидационный результат.

## Результат при одинаковом бюджете точных оценок

Положительные значения означают более высокую устойчивость найденных RankNet сетей. Эффект рассчитан через среднее парных логарифмов отношений R с равным весом исходных тестовых графов; это относительные проценты, не процентные пункты.

| Сравнение RankNet с | Основные 4 сценария | 32 новых сценария |
|---|---:|---:|
| GNN MSE | +3,10% | +3,22% |
| GNN log-MSE | +3,06% | +3,13% |
| Эволюционный поиск без суррогата | +5,17% | +5,54% |
| Случайный выбор из такого же пула кандидатов | +4,96% | +4,72% |
| Hill climbing | +1,55% | +2,75% |
| Независимый случайный поиск | +5,87% | +5,87% |

Для основного сравнения с MSE 95% bootstrap-интервал по восьми исходным тестовым графам: **[+1,70%; +4,64%]**. Средний по seed результат лучше на 8 из 8 графов. Интервал условен на одной обучающей выборке; seed поиска и обучения не считаются независимыми тестовыми задачами. На новых сценариях интервал составляет [+2,04%; +4,52%]. Финальные решения переоцениваются без повторного отбора.

## Дополнительные проверки и интерпретация

Все 240 финальных графов прошли независимую проверку ограничений и полное воспроизведение четырёх траекторий атаки через NetworkX. Расхождение равно нулю. Семь автоматических тестов проходят.

На валидации средняя точность порядка нетождественных пар составляет 69,6% для RankNet против 59,1% для MSE. Вместе с контролем случайного отбора из того же пула это согласуется с объяснением через более удачный отбор кандидатов. Это диагностическое наблюдение, а не доказательство единственного механизма преимущества.

После просмотра поведения регрессии дополнительно проверена глобальная нормализация целей вместо нормализации внутри исходной сети. Она ухудшила валидационный критерий: 0,04794 для global-MSE и 0,05074 для global-log-MSE против 0,03341 для исходного MSE; меньше лучше. Исходный MSE сохранился как выбранный бейзлайн, дополнительные тестовые поиски для этих вариантов не выполнялись. Это отдельная исследовательская проверка, не часть исходного замороженного протокола.

## Время и быстрый точный оценщик

Добавлен точный оценщик, который вычисляет порядок адаптивного удаления вершин, а затем восстанавливает размеры компонент обратным добавлением вершин через union-find. Он воспроизводит все основные траектории всех 240 финальных графов без расхождений. Исходный пилот использовал BFS; новый вариант включается настройкой `oracle: "union_find"` и не меняет сохранённый протокол пилота.

После завершения обучения выполнены 16 последовательных повторов с быстрым оценщиком: первый тестовый граф каждой комбинации семейства и размера, первые seed, четыре метода. Все результаты поиска совпали с исходными. Среднее время при бюджете 96 оценок: RankNet **4,13 с**, MSE **3,94 с**, EA **0,80 с**, hill climbing **0,71 с**. Это ограниченная проверка времени, не новые статистические повторности. Время предварительного обучения сюда не входит. Часть исходных измерений времени пересекалась с дополнительным обучением, поэтому для оценки накладных расходов предпочтительнее этот последовательный повтор.

**Пилот показывает преимущество по качеству при равном числе оценок, но не показывает ускорения по времени.** Для таких небольших сетей точная оценка достаточно дешева. Сравнение качества при равном времени в этом пилоте не проводилось.

## Что использовать в статье

Допустимая формулировка: «В пилотной задаче перестройки сетей с сохранением степеней ранжирующий GNN-суррогат обеспечил более высокую устойчивость, чем регрессионный GNN той же архитектуры, при одинаковом бюджете точных оценок».

До окончательного вывода нужны независимые обучающие выборки и больше исходных тестовых сетей, включая проверку переноса на другие размеры. Существующие восемь тестовых графов после анализа следует считать исследовательским набором. Следующий протокол должен отдельно учитывать бюджет вычислений и предварительного обучения.
